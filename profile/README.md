# Pozzo Research Group · University of Washington

Software, hardware designs and code for publications from the [Pozzo Research Group](https://pozzorg.com).

Science Jubilee documentation: [science-jubilee.readthedocs.io](https://science-jubilee.readthedocs.io/en/latest/)


## Analysis, modeling & data management

| Repository | Description |
|---|---|
| [activephasemap](https://github.com/pozzo-research-group/activephasemap) | Active sampling based strategies for constructing 'phase' maps using spectroscopic measurements |
| [autophasemap](https://github.com/pozzo-research-group/autophasemap) | Automatic Structure Phase Map (autophasemap) generation |
| [bayesian-optimization-tools](https://github.com/pozzo-research-group/bayesian-optimization-tools) | Collection of tools to run an off-the-shelf Bayesian optimizations with the current experimental set up in the Pozzo group |
| [designspacediscovery](https://github.com/pozzo-research-group/designspacediscovery) | Cheminformatics workflow to find new candidate compounds with desired properties |
| [hardy](https://github.com/pozzo-research-group/hardy) | Handling Arbitrary Recognition of Data! y not? |
| [MC-DFM](https://github.com/pozzo-research-group/MC-DFM) | The Monte Carlo Distribution Function Method (MC-DFM) is applied to model the small angle scattering curves of large biomolecular assemblies. |
| [micelles](https://github.com/pozzo-research-group/micelles) | Form factors ofblock copolymer micelles with spherical, ellipsoidal and cylindrical cores |
| [pispis](https://github.com/pozzo-research-group/pispis) | This repository include the protocol and tools for running an experiment on absolute scaling on pispis |
| [saxs_data_processing](https://github.com/pozzo-research-group/saxs_data_processing) | Tools for processing SAXS data. Mostly geared towards data from Xenocs instrument |
| [theia](https://github.com/pozzo-research-group/theia) | Tools and a NOMAD Oasis plugin for converting SAXS and UV-Vis data to NeXus (NXcanSAS) files |

## Lab automation & open hardware

| Repository | Description |
|---|---|
| [AFL-sample-loader](https://github.com/pozzo-research-group/AFL-sample-loader) | The automation software that powers the NIST Autonomous Formulation Lab! A flexible, web-based backend for device integration, drivers for some devices we've found useful, and glue that makes the AFL run. |
| [Automation-Hardware](https://github.com/pozzo-research-group/Automation-Hardware) | Pozzo Group OT2 Hardware |

| [sonication_station](https://github.com/pozzo-research-group/sonication_station) | Using Jubilee3D for sample preparation with sonication |
